## 1. 部署概述

### 1.1 手册目的与适用范围

**手册目的**：
- 提供端到端可复现的部署操作指南，确保开发、测试、生产三环境部署标准化可复现
- 明确运维监控与故障处理的标准流程，保障系统稳定运行
- 规范安全加固和敏感信息管理标准，符合等保合规要求

**适用范围**：
- 后端微服务（Spring Boot 2.7.14 + Java 11 + MyBatis Plus 3.5.3.1 + JWT 0.11.5 + Redis + MySQL 8.0.33）
- 前端 Web 管理后台（Vue 3.5.34 + Vite 8.0.12 + TypeScript 6.0.2 + Element Plus 2.14.2 + Pinia 3.0.4 + Vue Router 5.1.0 + ECharts 6.1.0 + Axios 1.18.0）
- 微信小程序（AppID：wx3ead2b8ed5519f92）
- 部署平台：微信云托管（Tencent CloudBase）

**拓扑说明**：

| 服务 | 说明 | 服务名 |

## 3. 微信云托管环境初始化

### 3.1 环境与服务创建步骤

**步骤 1：开通微信云托管服务**

1. 登录微信云托管控制台：https://console.cloud.tencent.com/tcb
2. 选择/新建云环境（建议命名：`rent1-env-test` / `rent1-env-prod`）
3. 选择「云托管 → 开通服务
4. 环境 ID 记录：后续配置时使用

**步骤 2：创建后端 API 服务**

1. 进入「云托管 → 服务管理 → 新建服务」
2. 服务名称：`rent1-backend`
3. 服务说明：房东租赁管理系统后端 API 服务
4. 网络访问：公网访问 + 私有网络访问
5. 创建成功后记录服务 ID

**步骤 3：创建前端静态服务（静态网站托管）

1. 进入「云托管 → 静态网站托管 → 新建」
2. 服务名称：`rent1-admin-web`
3. 说明：房东租赁管理系统 Web 管理后台
4. 索引文档：`index.html`
5. 错误文档：`index.html`（SPA 路由回退）
6. 创建成功后记录服务 ID

**服务命名规范汇总**：

| 服务 | 命名 | 示例 |
|------|------|------|
| 云环境 ID | rent1-env-{test\|prod} | rent1-env-prod |
| 后端服务 | rent1-backend | rent1-backend |
| 前端静态 | rent1-admin-web | rent1-admin-web |
| MySQL 实例 | rent1-mysql-{test\|prod} | rent1-mysql-prod |
| Redis 实例 | rent1-redis-{test\|prod} | rent1-redis-prod |

### 3.2 网络与安全配置

**私有网络配置**

1. 云托管默认使用私有网络，后端服务与数据库在同一 VPC
2. 确保后端服务端口：`8080`
3. 前端静态托管端口：`80/443`

**端口开放配置**：

| 服务 | 监听端口 | 公网访问 | 说明 |
|------|---------|----------|------|
| 后端 API | 8080 | HTTPS（通过云托管网关自动分配域名访问 | 云托管默认启用 HTTPS |
| 前端静态 | 80/443 | HTTPS | 静态网站托管自动 HTTPS |

**跨域 CORS 白名单**：

后端已在 `backend/src/main/java/com/rent1/api/config/CorsConfig.java` 已配置允许所有 Origin（`addAllowedOriginPattern("*")`），生产环境建议限制为具体域名列表。

**微信生态鉴权配置**：

1. 小程序后台 → 开发管理 → 开发设置 → 服务器域名
2. request 合法域名：添加云托管后端服务域名（如 `https://xxxx.service.tcloudbase.com`）
3. 上传文件域名：同上述
4. 下载文件域名：同上述

## 4. 后端服务部署（DDD 架构适配）

### 4.1 修改 application.yml 配置

**需将 `backend/src/main/resources/application.yml` 修改为支持环境变量注入的生产版本**：

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  application:
    name: rent-management-backend

  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://${DB_HOST:localhost}:${DB_PORT:3306}/${DB_NAME:rent_db}?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: ${DB_USERNAME:root}
    password: ${DB_PASSWORD:}

  redis:
    host: ${REDIS_HOST:localhost}
    port: ${REDIS_PORT:6379}
    password: ${REDIS_PASSWORD:}
    database: ${REDIS_DATABASE:0}
    timeout: 3000ms
    lettuce:
      pool:
        max-active: 8
        max-wait: -1ms
        max-idle: 8
        min-idle: 0

mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  type-aliases-package: com.rent1.domain.**.entity
  global-config:
    db-config:
      id-type: assign_id
      logic-delete-field: deleted
      logic-delete-value: 1
      logic-not-delete-value: 0
  configuration:
    map-underscore-to-camel-case: true
    # 生产环境关闭 SQL 日志，避免泄露敏感信息
    log-impl: org.apache.ibatis.logging.nologging.NoLoggingImpl

jwt:
  secret: ${JWT_SECRET:your-256-bit-secret-key-for-jwt-signing}
  expiration:
    user: 86400000
    admin: 28800000

crypto:
  aes:
    secret-key: ${AES_SECRET_KEY:32-char-secret-key-here}

request:
  security:
    signature-secret: ${REQUEST_SIGNATURE_SECRET:rent1-default-signature-secret}

wechat:
  appid: ${WECHAT_APPID:}
  secret: ${WECHAT_SECRET:}

logging:
  level:
    com.rent1: ${LOG_LEVEL:INFO}
    org.springframework: INFO
```

### 4.2 Dockerfile 编写

在 `backend/Dockerfile` 创建多阶段构建：

```dockerfile
# ========================================
# 阶段 1：构建阶段 - 使用 Maven 3.9 + JDK 11
# ========================================
FROM maven:3.9-eclipse-temurin-11 AS builder

WORKDIR /app

# 仅复制 pom.xml 先行，利用 Docker 缓存
COPY pom.xml .

# 下载依赖（加速后续构建
RUN mvn dependency:go-offline -B

# 复制源代码并构建
COPY src ./src

# 构建 JAR 包（跳过测试）
RUN mvn clean package -DskipTests -B

# ========================================
# 阶段 2：运行阶段 - 使用 OpenJDK 11 JRE Slim
# ========================================
FROM openjdk:11-jre-slim

WORKDIR /app

# 从构建阶段复制 JAR 文件
COPY --from=builder /app/target/rent-management-backend-1.0.0.jar app.jar

# 暴露端口
EXPOSE 8080

# 健康检查 - 检查 /api/health
HEALTHCHECK --interval=30s --timeout=10s --start-period=60s --retries=3 \
  CMD curl -f http://localhost:8080/api/health || exit 1
```

### 7.1 灰度策略

**阶梯放量策略**：

| 阶段 | 灰度比例 | 观察时长 | 观察指标 |
|------|---------|---------|---------|

- 接口平均响应时间（> 2s → 告警）
- 实例 CPU 使用率（> 80% → 告警）
- 实例内存使用率（> 80% → 告警）
- 数据库连接数（> 80% → 告警）
- Redis 命中率（< 90% → 告警）

### 7.2 流量切换

**云托管灰度发布配置方法**：

1. 云托管 → 服务管理 → `rent1-backend` → 版本管理

3. 配置灰度比例（5% → 20% → 50% → 100%）
4. 配置流量分配方式（按请求权重分配）
5. 点击「开始发布」

### 7.3 回滚触发条件

| 触发条件 | 严重程度 | 回滚方式 |
|----------|---------|---------|
| 服务不可用（健康检查连续失败 > 3 次 | 紧急 | 立即一键回滚 |
| 核心业务接口错误率 > 5% | 严重 | 立即回滚 |
| 性能骤降（响应时间 > 5s 持续 10 分钟） | 严重 | 立即回滚 |
| 安全问题（数据泄露/权限绕过） | 紧急 | 立即回滚 + 安全审计 |
| 数据库变更导致数据不一致 | 严重 | 回滚 + 数据修复 |

### 7.4 回滚操作

**一键回滚步骤**：

1. 云托管 → 服务管理 → `rent1-backend` → 版本管理

## 10. 安全加固规范

### 10.1 敏感信息管理

**环境变量统一管理**：

- 所有密钥、密码、Token 统一通过云托管环境变量管理
- 禁止在代码、配置文件中硬编码敏感信息
- 敏感环境变量勾选「加密」存储

**密钥硬编码排查**：

```bash
# 定期执行以下命令检查代码中是否有硬编码密钥
cd c:\Users\Alex\rent1

# 搜索 Java/TS/JS 中的硬编码
Get-ChildItem -Recurse -Include *.java,*.ts,*.js | Select-String -Pattern '(?i)(password|secret|api.?key).{0,30}'

# 搜索配置文件中的明文
Get-ChildItem -Recurse -Include *.yml,*.yaml,*.properties,*.json | Select-String -Pattern '(?i)(password|secret).{0,30}'
```

**配置文件加密**：

- `application.yml` 中敏感配置通过 `${ENV_VAR}` 注入
- `.env.production` 中 `VITE_API_BASE_URL` 不包含密钥

**权限最小化原则**：

- 数据库账号仅授予必要权限（SELECT/INSERT/UPDATE/DELETE）
- 数据库账号禁止授予 FILE/SUPER 等高危权限
- 运维人员使用独立账号，禁止使用 root 账号

### 10.2 访问安全

**IP 白名单**：

- 测试环境：限制为测试人员办公 IP 范围
- 生产环境：限制为必要的业务访问 IP 范围
- 云托管 → 服务管理 → 安全配置 → IP 白名单

**接口鉴权**：

- 所有业务接口必须经过 JWT Token 鉴权
- 管理后台接口必须经过管理员权限校验
- 权限不足返回 403 Forbidden

**防刷限流**：

- 登录接口限流（同一 IP 5 分钟内最多 10 次失败尝试）
- API 接口 QPS 限流（单用户 QPS 限制）

**操作日志审计**：

- 记录所有登录/登出操作
- 记录所有敏感操作（创建/更新/删除）
- 记录所有权限变更操作
- 日志包含：操作人、操作时间、IP 地址、操作内容

### 10.3 数据安全

**传输全程 HTTPS**：

- 前端 Web 管理后台强制 HTTPS
- 小程序请求强制 HTTPS
- 禁止 HTTP 明文传输

**数据库加密存储**：

- 手机号、身份证号等敏感字段 AES 加密存储
- 密码使用 BCrypt 哈希存储（不可逆）
- 数据库连接使用 SSL/TLS 加密连接

**备份加密**：

- 数据库备份文件加密存储
- 备份文件访问权限限制

**脱敏规则**：

| 字段 | 脱敏规则 | 示例 |
|------|---------|------|
| 手机号 | 前 3 位 + **** + 后 4 位 | 138****5678 |
| 身份证号 | 前 6 位 + ******** + 后 4 位 | 440101********1234 |
| 姓名 | 第 1 字 + *** | 张*** |

### 10.4 漏洞防护

**依赖安全扫描**：

```bash
# 后端依赖安全扫描
cd backend
# 使用 OWASP Dependency-Check 或类似工具
# 定期执行依赖安全扫描

# 前端依赖安全扫描
cd ../admin-web
npm audit
# 修复高危漏洞
```

**常见 Web 漏洞防护**：

| 漏洞类型 | 防护措施 |
|----------|---------|
| SQL 注入 | 使用 MyBatis Plus 参数化查询，禁止拼接 SQL |
| XSS 跨站脚本 | 前端输入过滤，后端输出转义 |
| CSRF 跨站请求伪造 | JWT Token 鉴权，同源策略 |
| 越权访问 | 数据权限隔离（DataScope），接口权限校验 |
| 敏感信息泄露 | 日志脱敏，错误信息不返回详细信息 |

**版本安全更新**：

- 定期检查 Spring Boot / MyBatis Plus / JWT 等依赖版本
- 关注 CVE 漏洞公告，及时升级存在漏洞的依赖版本
- 至少每季度执行一次安全审计
